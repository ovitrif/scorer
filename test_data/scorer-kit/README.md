# scorer-kit fixtures

These JSON files are decoded scorer snapshots generated by `scorer-kit decode`.
They use sanitized labels so the fixtures document scorer structure without
embedding local paths, URLs, or source-specific names.

- `source-a.decoded.json`: decoded scorer sample A.
- `source-b.decoded.json`: decoded scorer sample B.
- `merged-richer-history.decoded.json`: decoded output from merging source-b
  first, then source-a, using `--policy richer-history`.
- `merged-richer-history.report.json`: merge audit report, including duplicate
  decisions and summary counts.

Regenerate with:

```sh
cargo run --bin scorer-kit -- decode <source-a.bin> \
  --label source-a \
  --compact \
  --save test_data/scorer-kit/source-a.decoded.json
cargo run --bin scorer-kit -- decode <source-b.bin> \
  --label source-b \
  --compact \
  --save test_data/scorer-kit/source-b.decoded.json
cargo run --bin scorer-kit -- merge <source-b.bin> <source-a.bin> \
  --label source-b \
  --label source-a \
  --output target/scorer-kit/merged.bin \
  --report test_data/scorer-kit/merged-richer-history.report.json
cargo run --bin scorer-kit -- decode target/scorer-kit/merged.bin \
  --label merged-richer-history \
  --compact \
  --save test_data/scorer-kit/merged-richer-history.decoded.json
```
